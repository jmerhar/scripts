# Utility Scripts

General-purpose user-facing utilities. For installation instructions, see the [main README](../../README.md#installation).

## Scripts

<!-- BEGIN TABLE -->
| Script | Description |
|---------|-------------|
| [`compare-dirs`](compare-dirs/) | Recursively compare two directories, reporting differences in existence, size, timestamps, and checksums. |
| [`dmarc-report`](dmarc-report/) | Aggregate a folder of DMARC reports into one summary, flagging unenforced domains, unaligned senders, and spoofing. |
| [`subtitle-report`](subtitle-report/) | Report subtitle coverage for a media library, by language and source (embedded tracks + sidecars). |
| [`subtitle-sync`](subtitle-sync/) | Resynchronize drifting subtitles to a video's speech using Whisper and `alass`. |
| [`unlock-pdf`](unlock-pdf/) | Decrypt a password-protected PDF file. |

<!-- END TABLE -->
